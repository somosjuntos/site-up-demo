# Site de demonstração — Unidade Pastoral de Nova Oeiras e São Julião da Barra

**Isto é uma demonstração.** O site oficial continua em https://www.unidadepastoral.com —
nada aqui mexe no domínio, no alojamento, nos e-mails ou no site actual.

## Ver o site

Depois de activado o GitHub Pages (Settings → Pages → Deploy from branch → main → /root),
o site fica disponível em:

**https://somosjuntos.github.io/site-up-demo/**

O site é uma página única (`index.html`), sem construção nem dependências.
Funciona em telemóvel e computador.

## O que contém

- Horários de missa, adoração e confissões das duas paróquias (retirados do site actual)
- Boletim da semana com ligação para o PDF
- Três notícias/eventos em destaque
- Secção Alpha (tema do ano pastoral «Vinde e Vede»)
- Contactos do cartório, e-mails, telefones e atendimento do pároco

## Como pedir ou fazer alterações

1. **Pedir ajuda à sua IA (ChatGPT, Gemini, etc.):** abra o ficheiro
   [`CONTEXTO-PARA-IA.md`](CONTEXTO-PARA-IA.md), copie o conteúdo para a conversa
   com a sua IA e diga-lhe o que quer mudar. Ela prepara o texto exacto da alteração.
2. **Aplicar a alteração:** quem tem acesso a este repositório pode editar o
   `index.html` aqui mesmo no GitHub (botão do lápis ✏️). Os blocos editáveis
   estão marcados com `✏️ EDITÁVEL`. Ao guardar ("commit"), o site actualiza sozinho
   em 1–2 minutos.
3. **Ou simplesmente pedir:** abra um *Issue* neste repositório com o modelo
   "Pedido de alteração" (precisa de uma conta GitHub gratuita), ou envie o pedido
   a quem lhe deu a conhecer esta demonstração.

A publicação é sempre feita por uma pessoa com acesso ao repositório —
nenhuma IA publica sozinha.

## Limites desta demonstração

- Conteúdo público retirado do site actual em 10 de novembro de 2026.
- Não substitui o site oficial enquanto a equipa pastoral não decidir.
- Alojamento: GitHub Pages (gratuito). Domínio, e-mails e boletins continuam onde estão.
